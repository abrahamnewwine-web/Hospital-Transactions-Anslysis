Project :NHS
Role: Business Analyst
Tools: Power BI, SQL
Business Challenge: The healthcare organization lacked a centralized analytics platform capable of delivering real-time visibility into hospital revenue performance, operational expenses, specialty profitability, procedure-level financial trends, and patient-service utilization across departments and regions.
Solution :an interactive healthcare financial analytics dashboard using Power BI and SQL to centralize hospital revenue KPIs, operational expenses, profit-margin analysis, specialty performance metrics, and procedure-level financial intelligence into a unified executive reporting platform.
Business Impact: profitability monitoring, executive financial oversight.
